Installing a mod

All of my mods are client-side mods for Fabric on Minecraft . They only go on your own computer, never on a server. If you've never used Fabric before, setup takes about five minutes.

  1. Install Fabric LoaderDownload the installer from fabricmc.net, run it, pick Minecraft and click Install.
  2. Download Fabric APIMost of my mods need it. Get the version for from Modrinth.
  3. Download the modPick a mod on the Mods page and click Download. You'll get a .jar file.
  4. Put both files in your mods folderOn Windows, press Win + R, type %appdata%\.minecraft\mods and press Enter. On Mac it's ~/Library/Application Support/minecraft/mods. Create the folder if it isn't there.
  5. Launch the gameIn the Minecraft Launcher, choose the fabric-loader- profile and click Play.

Using a launcher like Prism or the Modrinth App? Create a Fabric instance and drop the .jar into that instance's mods folder instead. Please only download the mods from this website.

Updating

Delete the old .jar from your mods folder, then put the new one in. Keeping both will crash the game. Each mod's Changelog tab shows what changed in every version.

Common questions

Do I need Fabric API?

For most mods, yes. Each mod page lists what it needs under Compatibility → Requires. If it says "Nothing else", you only need Fabric Loader.

Do the mods work on servers?

Yes. Every mod is client-side, so you install it only on your own computer and it works when you join any server, even a vanilla one. Nothing needs to be installed on the server. Just make sure the server's rules allow client-side mods.

Can I share a mod with a friend or put it in a modpack?

Please don't share the files. The mods are for personal use only, so send your friend a link to this website and they can download it themselves. That way everyone gets the newest, safe version. See Terms & conduct for the details.

Can I make a video or stream with the mods?

Yes. Just don't put the mod files in your description. Link to this website instead.

Is the source code available?

No. The mods are closed source, and decompiling or editing them isn't allowed. If you have an idea or found a problem, tell me on Discord.

Will you make a Forge, NeoForge or older-version port?

Not right now. I focus on Fabric for so every mod stays polished and up to date.

My game crashes on launch. What do I do?

First make sure you're on Minecraft , Fabric API is installed, and there's only one version of each mod in your folder. If it still crashes, send me your crash report (see below).

Reporting a bug

Report bugs on Discord. The more detail you give, the faster I can fix it. Please include:

  • The mod's name and version
  • Your Fabric Loader and Fabric API versions
  • A list of your other mods
  • What you did, what you expected, and what happened instead
  • Your crash report or latest.log, uploaded to mclo.gs

Crash reports are in your .minecraft/crash-reports folder, and the log is in .minecraft/logs.
