Installing a mod

All of my mods are for Fabric on Minecraft . If you've never used Fabric before, it takes about five minutes.

  1. Install Fabric LoaderDownload the installer from fabricmc.net, run it, pick Minecraft and click Install.
  2. Download Fabric APIMost of my mods need it. Get the version for from Modrinth.
  3. Download the modPick a mod on the Mods page and click Download. You'll get a .jar file.
  4. Put both files in your mods folderOn Windows, press Win + R, type %appdata%\.minecraft\mods and press Enter. On Mac it's ~/Library/Application Support/minecraft/mods. Create the folder if it isn't there.
  5. Launch the gameIn the Minecraft Launcher, choose the fabric-loader- profile and click Play.

Using a launcher like Prism, Modrinth App or CurseForge? Create a Fabric instance and drop the .jar into that instance's mods folder instead.

Updating

Delete the old .jar from your mods folder, then put the new one in. Keeping both will crash the game. Each mod's Changelog tab shows what changed in every version.

Common questions

Do I need Fabric API?

For most mods, yes. Each mod page lists what it needs under Compatibility → Requires. If it says "Nothing else", you only need Fabric Loader.

Can I put these mods in my modpack?

Yes. You're welcome to include them in any modpack, public or private. A link back to this site or my GitHub is appreciated. See Terms & conduct for the details.

Does it work on servers?

Check the Environment on the mod's page. Client mods only go on your computer and work on any server. Server mods only go on the server. Client or server mods should be installed on both.

Will you make a Forge, NeoForge or older-version port?

Not right now. I focus on Fabric for so every mod stays polished and up to date. You can suggest ports in the Discord.

My game crashes on launch. What do I do?

First make sure you're on Minecraft , Fabric API is installed, and there's only one version of each mod in your folder. If it still crashes, send me your crash report (see below).

Is it safe to add or remove a mod from an existing world?

Back up your world first, always. Mods that add blocks or items will remove them from your world if you uninstall the mod later.

Reporting a bug

The more detail you give, the faster I can fix it. Please include:

  • The mod's name and version
  • Your Fabric Loader and Fabric API versions
  • A list of your other mods
  • What you did, what you expected, and what happened instead
  • Your crash report or latest.log, uploaded to mclo.gs

Crash reports are in your .minecraft/crash-reports folder, and the log is in .minecraft/logs.
